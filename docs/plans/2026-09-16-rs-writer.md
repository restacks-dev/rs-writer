# RS Writer implementation

## Goal
A native macOS Markdown writing app with a user-selected, persistent library folder suitable for an existing cloud sync provider or mounted shared drive.

## Architecture
SwiftUI window and library, AppKit NSTextView editor, bundled offline Markdown renderer in WKWebView. Plain UTF-8 Markdown files remain the source of truth. Security-scoped bookmarks remember folder access. Coordinated file operations, content comparison before saving, conflict copies and local recovery protect edits. Polling detects remote changes; the drive provider owns synchronization.

## Work
1. Create Xcode project, sandbox entitlements, app metadata and Swift package tests.
2. Implement file library, safe saving, recovery, folder restoration and external change detection.
3. Implement three-column writing interface, search, folders, file creation/rename, editor styling, focus mode, outline, statistics and keyboard shortcuts.
4. Add offline preview and HTML/PDF export, appearance and editor settings.
5. Test storage conflict cases and Markdown escaping; build the macOS app and inspect its UI.
6. Document building, Developer ID signing/notarization and shared-drive behavior.

## Completion criteria
The application builds locally; storage tests cover external edits and missing files; no remote services are needed to write or preview. Xcode supports signing with the user's own Team. Explain remaining differences from iA Writer and any verification limitations.

## Scope
macOS 14+. Own name and UI assets. This version implements the core local Markdown workflow; authorship tracking, publishing integrations and DOCX conversion are separate follow-up features.

## Delivered
Native app, Xcode project, universal locally signed release, offline preview, coordinated file operations and persistent folder bookmarks are implemented. Ten storage tests pass; UI creation/save/preview/external-refresh and sandbox bookmark restoration were verified. See `docs/VALIDATION.md` and `README.md` for exact coverage and remaining parity work.
